# Full VERL backup for noise experiments

This directory is a complete source snapshot of the active `POLARIS-main/verl`
tree at the time the noise experiment backup was assembled (701 files).

It includes the ordinary VERL framework, plus all hidden-state/weight-noise
modifications present in the active tree.  It contains source, configuration,
tests, examples, and dependency declarations, but no checkpoints, datasets,
run outputs, Python caches, or external package environments.

For the noise-specific entry points and environment contract, see the parent
directory's `README.md` and `ENVIRONMENT.md`.
